## 💡 MVP(Minimum Viable Product) Definition

본 프로젝트의 MVP는
사용자가 자신의 목표와 습관을 기록하고,
하루 단위로 실행 여부를 체크할 수 있는 최소 기능 세트이다.

---

## ✅ In Scope (MVP)

### 1. 목표 / 만다라트

- 만다라트 3x3 생성
- 중앙 목표 1개 설정
- 하위 목표 최대 8개 입력
- 목표 수정 / 삭제
- pdf / 이미지 다운로드

### 2. 습관 관리

- 습관 대시보드
- 습관 생성 / 수정 / 삭제
- 습관 완료 체크 (일 단위)
- 완료 여부 시각적 표시
- pdf / 이미지 다운로드

### 3. 버킷 리스트

- 버킷 리스트 생성 / 완료 / 삭제

### 4. 기본 화면

- 서비스 설명
- 매뉴얼 팝업

---

## ✅ Out of Scope (Not MVP)

- 회원가입 / 로그인 (아이디, 닉네임)
- 소셜 로그인
- 알림 기능
- 통계 / 리포트
- 다중 만다라트 관리
- 데이터 공유 기능
- 모바일 앱

---

## ✅ Post-MVP (Backlog)

- 습관 달성률 통계
- 캘린더 뷰
- 알림 (푸시 / 이메일)
- 다크모드
- 5년 일기 기록

---

## ✨ MVP Completion Criteria

다음 조건을 만족하면 MVP 완료로 판단한다.

- 만다르트 표를 생성할 수 있다
- 습관을 매일 체크할 수 있다
- 버킷 리스트를 생성할 수 있다
