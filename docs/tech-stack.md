## ✅ Frontend Tech Stack

### Framework

- **Next.js (App Router)**
  - 페이지 단위 라우팅과 레이아웃 관리가 명확함
  - 향후 SEO 및 서버 컴포넌트 확장 가능성 고려

### Language

- **TypeScript**
  - 컴파일 단계에서 오류를 방지하여 안정적인 개발 가능
  - 백엔드 API 타입과 연계 가능

### UI Library

- **MUI (Material UI)**
  - 빠른 UI 구성 가능
  - 일관된 디자인 시스템 유지

### State Management

- **(초기) React useState / useContext**
- **(확장) Redux Toolkit or Zustand**
  - 전역 상태(습관, 만다라트, 유저 설정 등) 관리 목적

### Styling

- **SASS**
  - 컴포넌트 단위 스타일 관리
  - 중첩, 변수 활용 가능

## ✅ Backend Tech Stack

### Runtime

- **Node.js**

### Framework

- **Express.js**
  - 구조가 단순하여 첫 백엔드 프로젝트에 적합
  - REST API 설계 학습 목적

### Database

- **MySQL**
  - 관계형 데이터 구조 학습
  - 습관, 만다라트, 투두 간 관계 표현에 적합

### ORM / Query

- **(예정) Prisma or Sequelize**
  - SQL 직접 작성 + 추상화 균형 고려

### API Style

- **REST API**
  - 프론트/백엔드 분리 구조에 적합

## ✅ Tech Selection Criteria

1. 학습 곡선이 완만할 것
2. 포트폴리오에서 설명 가능한 기술일 것
3. 추후 확장(기능 추가, 구조 개선)이 가능할 것
4. 프론트엔드 개발자로서 강점을 드러낼 수 있을 것
